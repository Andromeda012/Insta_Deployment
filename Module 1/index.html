💡 Global Kapak Yönetim Paneli Rehberi

Bu panel, sitenizdeki tüm içerikleri doğrudan GitHub ve Vercel bulut altyapısına bağlayarak yönetmenizi sağlar.


🚀 Nasıl Çalışır?

  1. Panelden ürün, fotoğraf, makale veya firma bilgisi ekleyip "Kaydet" dediğinizde, veriler anında bulut sunucunuza işlenir.
  2. Vercel bu güncellemeyi 15 saniye içinde tüm dünyadaki ziyaretçilerinize canlı olarak sunar.
  3. Fotoğraflarınız sunucuya optimize edilerek yüklenir, siteniz hiçbir zaman yavaşlamaz.

🔑 API Anahtarı Hakkında

Sağ üstteki "⚙️ API & Depo Ayarları" butonundan token ve depo ayarlarınızı istediğiniz zaman güncelleyebilirsiniz. Bu bilgiler sadece kendi tarayıcınızda güvenle saklanır.

⚙️ GitHub API & Depo Ayarları

Panelinizin sitenize doğrudan veri yazabilmesi için GitHub ayarlarınızı buradan yapılandırın.

Nasıl Token Alınır? (1 Dakika):
1. Buraya tıklayarak GitHub token sayfasını açın.
2. "repo" kutucuğunu işaretleyin ve en alttaki yeşil "Generate token" butonuna basın.
3. Size verilen ghp_... ile başlayan kodu kopyalayıp yukarıdaki kutuya yapıştırın.
