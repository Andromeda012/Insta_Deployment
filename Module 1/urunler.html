💡 Global Kapak Yönetim Paneli — Supabase Bulut Mimarisi

Bu panel, sitenizdeki tüm içerikleri doğrudan Supabase PostgreSQL Veritabanı ve Supabase Storage (Medya Depolama) bulut altyapısına bağlayarak anlık olarak yönetmenizi sağlar.


🚀 Nasıl Çalışır?

  1. Panelden ürün, tedarikçi, galeri fotoğrafı, blog makalesi veya firma bilgisi ekleyip "Kaydet" dediğinizde, verileriniz doğrudan Supabase Database tablolarına (products, suppliers, gallery, blogs, site_settings) kaydedilir.
  2. Seçtiğiniz veya sürükleyip bıraktığınız ürün fotoğrafları, logolar ve kurumsal tanıtım videoları doğrudan Supabase Storage (media bucket) içerisine yüklenir ve yüksek hızlı CDN bağlantısı oluşturulur.
  3. Canlı kurumsal web siteniz (Global-Mobilya-Web) verileri doğrudan Supabase'den okuduğu için, yaptığınız her değişiklik bekleme süresi olmadan anında web sayfasına yansır.

⚡ Supabase Kurulumu & Bağlantı

Sağ üstteki "⚡ Supabase Bulut Ayarları" butonundan Supabase Project URL ve Anon Key bilgilerinizi girebilir, tek tıkla SQL kurulum kodunu kopyalayabilir ve mevcut verilerinizi Supabase'e aktarabilirsiniz.

Güvenli Yönetici Girişi

İçerik yönetimi için yetkili Supabase hesabınızla giriş yapın. Yalnızca admin ve content_manager rolleri kabul edilir.

Sunucu bağlantı ayarları Vercel ortam değişkenlerinden yönetilir.
